# 受け口とプロンプト無しの新規セッション（2026-11-11）

ブランチ feat/lobby の実装の前と後に、手元で確かめたことの記録。本番のノード（4323）は使っていない。

## 実装の前に確かめたこと

### SDK の sessionId

- SDK 0.3.318 の `query()` に `sessionId`（UUID）を渡し、入力を8秒止めてから1通目を入れた。claude は 2.1.322。
- init と result の `session_id` は、指定した id と同じだった。jsonl は `~/.claude/projects/-private-tmp-ccn-lobby-exp-work/<指定した id>.jsonl` にできた。
- 1通目を入れる前は、init も jsonl も無かった。claude のプロセスは 2.8 秒の時点で起動していた（`commands_changed` が届いた）。
- 1通目を待つ claude 1体の RSS は約 300MB だった（`ps -o rss` で 309264 KB。ユーザー設定の MCP サーバーの子プロセスは含まない）。
- 遅延起動した形（入力を3秒止めてから1通目）で Bash に `echo $CLAUDE_CODE_SESSION_ID` を実行させると、指定した id が出た。

### 3台の roots

`/api/host` をサービストークンで読んだ。

| --- | --- | --- |
| konaito-pro | `/Users/konaito` | 2.1.322 |

### ノードの子から子を立てる手段

別ポート（4391）と別設定（`CCN_CONFIG`）の試験ノードを立て、そのノードが立てたセッションに試させた。

- ccn CLI（`ccn new`）は通った。子の `parent` は `agent:lobbytest/5068f3cb/parent` になり、親子として並んだ。
- ccn の MCP（`create_session`）も通ったが、子の `parent` は `local` になった。
- 最初の試験では CLI が `bun: not found` で失敗した。試験ノードを立てたシェルの PATH に `~/.bun/bin` が無かったためで、本番の常駐の PATH（plist）には `~/.bun/bin` と `~/.local/bin` がある。

## 実装の後に確かめたこと

試験ノードの設定は `{ "name": "lobbytest", "port": 4391, "roots": ["/private/tmp/ccn-lobby-exp"], "lobby": "/private/tmp/ccn-lobby-exp/lobby" }`。PATH の先頭に worktree の `bin` を置き、子が呼ぶ `ccn` をこのブランチの版にした。

### 受け口の CLAUDE.md の読み込み

- ノードの起動で `lobby/CLAUDE.md` ができた。
- 受け口のセッションに、ツールを使わずに CLAUDE.md の見出しと最初の箇条を書き写させた。2つとも書き出した内容と一致した。信頼の確認は出なかった（SDK の起動は確認を出さない）。

### 3つの経路

| 経路 | 受け口 | 依頼 | 返った子 | 子の parent | 結果 |
| --- | --- | --- | --- | --- | --- |
| CLI（`ccn new` → `ccn run`） | `cf512d84` | greeter の hello.sh を「こんにちは」にする | `lobbytest/bd047062-…` | `agent:lobbytest/cf512d84/lobby` | hello.sh が書き換わった |
| MCP（試験ノードの `/mcp` を SDK のクライアントで直接） | `8e1f7da6` | notes に memo.md を作る | `lobbytest/28139b37-…` | `agent:lobbytest/8e1f7da6/lobby` | memo.md ができた |
| 画面（agent-browser） | `f59df108` | notes に todo.md を作る | `lobbytest/63faca7c-…` | `agent:lobbytest/f59df108/lobby` | todo.md ができた |

- どの経路でも、受け口は `子: <peer>/<sessionId>` を完全な UUID で返し、子の結果を待たずにターンを終えた。
- 画面では、場所を空にして開くと空の会話が出て、入力欄にフォーカスが当たった。返事の `子:` の行を押すと、子の会話が開いた。
- 古い版のノードの表示は、画面の中の `hosts` と `fetch` を差し替えて確かめた。古い版のノードそのものには当てていない。
- スクリーンショットは `/private/tmp/ccn-lobby-exp/shots/` にある（一時的な置き場）。
